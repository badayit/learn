# Patente Facile

App mobile per preparare l'esame di teoria della patente B in Italia, con traduzione e spiegazioni in arabo.
تطبيق للتحضير لامتحان النظري لرخصة السياقة B في إيطاليا، مع الترجمة والشرح بالعربية.

- **Corsi**: lezioni per argomento con audio (italiano + arabo).
- **Simulazione d'esame**: 30 domande Vero/Falso, 20 minuti, massimo 3 errori.
- **Argomenti**: allenamento per tema con spiegazione dopo ogni risposta.
- **Segnali**: i segnali stradali principali.
- **Errori**: ripasso delle domande sbagliate (salvate sul telefono).

`app.html` è il file sorgente. Dopo una modifica, esegui `./build.sh` per rigenerare `index.html`.
Apri `index.html` nel browser del telefono e usa "Aggiungi a schermata Home".
